[1.7.0]

Added:
- /glint cheat to unlock every Glint Table design at once
- Several Advancements
- Trim import to the Glint Table: save any build you preview to a file and pull it back later as a build target that unlocks once you print it
- On servers, operators can share a set of blueprint trims that everyone sees in the import list
- The Glint Table now lets you build and preview a trim from any design, dye, glow, or name freely; the materials are only required and consumed when you print
- Save Design in the wand editor: save your current build to the server so anyone can import it later through the wand or the Glint Table (delete saved designs from the Import list with the trash icon)
- Hover tooltips on every button and control, in both the wand editor and the Glint Table
- Swap two colors, or two layers, by selecting one and shift-clicking another; shift-right-click a dye to remove just that color from a blend
- Rainbow Dye now has a JEI info page describing how it's used at the Glint Table

Fixed:
- The wand editor now works in survival as long as you're holding the wand, instead of requiring creative mode
- Importing a trim in the wand editor now keeps its glow colors instead of dropping them, and refills its custom name
- The wand editor's Import search box now accepts typed text
- Importing a trim you already own no longer leaves a duplicate in the Glint Table's printed list
- Every color on every layer of a printed trim now costs its dye (a matching dye per shade, a Rainbow Dye per custom color)
- /glint glow no longer needs a glint on the item or entity; a glowing outline can stand on its own and shows white when there's no glint color
- The Glint Table now drops itself when broken
- Picking black for a glint color now hides that layer, so you can leave a gap in a design

Altered:
- Picker scroll bars in the Glint Table and wand editor can now be dragged with the mouse
- The Glint Table's Print tooltip is tidier, dropping the "Can't print yet" and "Consumes" headings
- The Glint Table's layer row now stays visible, and the color row appears once you start building a trim
- Glint Table tooltips are now a clean white to match the wand editor


[1.6.0]

- Added the Glint Table: a block for building and printing trims with a slot-based editor, crafted from iron blocks, a crafting table, a smithing table, and a Glint Trim
- Added the Chromatic design, a procedural animated oil-slick that blends up to 8 colors
- Added eight scroll directions and a manual offset for the glint animation
- Added a Rainbow Dye item
- Added crafting to set a trim's glint brightness

- Glint Trim chest loot can now also drop Rainbow Dye and the layer and black tears
- Fixed the wand editor's glint-import search box not filtering the list
- The 16 named glint colors now match Minecraft's dye colors exactly
- The Glint Table and wand editor are now fully translatable, with Spanish included

[Compat]
- Compatible with Iris Shaders


[1.5.0]

Ported to NeoForge 1.21.1.

Added:
- The wand now carries the glint you are editing. It updates live when you import a saved trim
  or change the preview item, so the wand in your hand always matches what is in the editor.
- Saved trim files now remember a custom display name and its color: /glint export writes them,
  and the wand's Import picker restores them when you load the trim back.

[Compat]
- Ice and Fire (Community Edition): player armor (copper, deathworm, dragonscale, sea serpent,
  troll, and the rest) now shows glints and glow outlines. CE routes this armor through its own
  renderer that bypassed the usual armor path, so it previously showed nothing.
- Ice and Fire (Community Edition): dragon, hippocampus, and hippogryph armor glints and glow
  outlines now stay on the armor instead of bleeding across the creature's body.
- Ice and Fire (Community Edition): glowing mount armor no longer leaks the back-side glow ring
  through transparent wings, feathers and fins, and water, clouds and ice behind those gaps stay
  visible instead of being hidden by an invisible plane.
- Ice and Fire (Community Edition): troll weapons now each get an outline that matches that
  weapon's shape, in hand and in the inventory, instead of every variant sharing one
  block-shaped glow.
- Ice and Fire (Community Edition): the tide trident's glow outline now traces the trident
  itself, both in hand and in the inventory slot, instead of filling a square.
- Epic Knights: armor decoration glints no longer disappear after toggling a shader pack off
  (they used to come back only after reloading the world).

Fixed:
- Glowing modded shields and other 3D-model items now trace the item's actual shape instead of
  covering the whole item with glow. This applies both held in hand and in the inventory slot.
- Held item glow outlines no longer shift or change shape as you turn the camera around them.
