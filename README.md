# Custom Glints — media

Image and animation assets (`.webp`, `.png`, `.gif`) for the Modrinth and CurseForge
pages and the Obsidian wiki. This is an orphan branch with no source history, so these
files never get pulled into a source checkout.

Reference a file from anywhere by its raw URL:

```
https://raw.githubusercontent.com/TunaMods/custom_glint/media/<file>.webp
```

Embed in a description or wiki page:

```markdown
![Glint Table editor](https://raw.githubusercontent.com/TunaMods/custom_glint/media/glint_table.webp)
```

Prefer animated WebP over GIF (full color, smaller files). Keep each clip to a few MB so
pages load fast.
